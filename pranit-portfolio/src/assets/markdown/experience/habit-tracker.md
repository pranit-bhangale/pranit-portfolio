# Habit Tracker – Full Stack Development Experience

## Overview
During this project, I served as the **Full Stack Developer** responsible for the end-to-end implementation of a scalable habit-tracking system. This role involved designing a robust backend architecture and an interactive, responsive frontend to provide users with a seamless experience.

## Technical Contributions

### Backend Architecture (Spring Boot & MySQL)
- **Layered Design**: Implemented a Clean Architecture following the Controller-Service-Repository pattern to ensure maintainability and testability.
- **Secure Authentication**: Integrated **JWT (JSON Web Token)** for stateless authentication and role-based access control.
- **Data Integrity**: Leveraged Hibernate JPA for efficient object-relational mapping and database migrations.

### Frontend Implementation (React & Tailwind CSS)
- **State Management**: Built complex form handling and real-time UI updates for habit tracking.
- **Responsive Design**: Used Tailwind CSS to create a mobile-first dashboard experience.
- **Interactive Visualizations**: Implemented progress bars and charts to help users visualize their consistency.

## Key Outcomes & Learning
- **Deployment**: Successfully deployed the application to a production environment, gaining experience in CI/CD and cloud hosting.
- **SOLID Principles**: Focused on decoupling the presentation layer from the business logic, which significantly improved the codebase's agility.
- **Performance**: Optimized SQL queries to handle large sets of user habit logs without latency.
